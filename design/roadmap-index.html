主页 · 历史

起始页 + 最近打开

无文件时的欢迎页:品牌头、打开/新建、搜索、最近打开历史列表(悬停删除、清空全部、空状态)。

 功能 ①

多文件标签

同一窗口打开多个 .md,顶部标签切换;未保存圆点、悬停关闭、⌘T 新开、⌘1~9 跳转。

 功能 ②③④

设置 · 样式 / 语言 / 快捷键

左导航两栏式设置:阅读样式画廊、界面语言单选、可录制的自定义快捷键。

 功能 ⑤

分栏编辑功能栏

分栏源码侧顶部的 Markdown 工具栏:标题、粗斜体、列表、引用、代码、链接、图片、表格等。
