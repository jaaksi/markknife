Markknife 使用指南

一个简洁的单文件 Markdown 查看 / 编辑器。本文用来演示目录面板。

快速开始

从工具栏的「打开文件」选择一个 .md,或直接用系统「打开方式」双击打开。默认进入查看模式。

打开文件

支持选择单个 Markdown 文件;也支持把本应用设为 .md 的打开方式。

三种模式

查看(只读)、编辑·所见即所得、编辑·分栏。三者共享同一份内容。

编辑

切换到编辑后可选两种子模式。

所见即所得

富文本直接编辑,数学公式、Mermaid、代码高亮、图片均支持。

分栏模式

左侧源码、右侧实时预览,可一键左右互换。

目录面板

右(或左)侧的目录由文档标题自动生成,点击可跳转,滚动时高亮当前章节。可随时收起,腾出空间。

设置

按 ⌘ , 打开设置。

外观

内容最大宽度、字号、行高。

自动更新

启动时静默检查,也可在设置里手动「检查更新」。
